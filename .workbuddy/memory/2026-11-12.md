### 核查到的事实

纯 Rust 开源参数化 3D CAD（MIT OR Apache-2.0），2026-10-07 建仓，
v0.40.1 于 2026-11-12 03:10 发布，约 13.3k stars / 8,409 commits。
能力：headless CLI、22 个 MCP 工具、STEP/IGES/STL/OBJ/glTF 读写、
`measure`（体积/面积/质心/包围盒）、参数化特征时间线、自带 oracle 参考件集。
**能力清单里完全没有 CAM**：无刀路生成、无 G-code、无材料去除仿真、
无过切/残留判据、无加工特征识别。

两个关键的不独立证据：
- `docs/oracle.md`：90 例中 69 例解析值、**21 例由 FreeCAD 1.1.4 计算**期望值；
  原文 "FreeCAD is not a dependency of SolidCraft" 指编译依赖，但几何基准仍来自 OCC。
- README 写参考件 75/76，`docs/oracle.md` 写 90/90，文档口径仍在漂移。

本机：无 `solidcraft-cli`、无 `C:\Program Files\SolidCraft`、无 cargo；
Windows 便携包 160 MB、MSI 122 MB 且**未签名**（SmartScreen 需手动放行）。

2. 它自身部分 oracle 基准由 FreeCAD 1.1.4 算，相对 OCC 不独立，
   拿它当「独立裁决者」逻辑上站不住，反而把 §6 已关闭的问题重新打开。
3. 它没有制造侧验收，接进来最多补一条几何链路，不产生新的论文结论。
4. 英文稿 6 图 + 4 表已用满期刊 ≤10 上限，新增实验必然挤掉现有图表，
   还要重跑 reproduce / figures / DATA-CARD，收益远低于风险。

**核对结果**：6 条现稿已主动披露，1 条读反，1 条已结案。清单按制造类期刊标准
评级，目标特刊是 trustworthy / evaluation protocols，整体偏高。

两处事实纠正（以后别再被带偏）：
- 「3.275% 刀具穿越」是误读。分母 9,660,095 个采样刀心点，316,398 个
  **过切标记**（`reports/m6_ocl_external.json`），是论文自审计产出，
  摘要/引言/结果/结论/cover letter 五处主动写。是卖点。
- 离散零过切全文 6 处限定；机理是柱心到柱心 vs 柱心到台阶边的半格盲区；
  分辨率收敛 1.332→0.432→0.143%（`m6_ocl.json::resolution_sweep`）；
  半格余量 2,822→41 但残留 ×4.42、双线 107/130。代价已量化，不是免责声明。

**真正风险**：不是"承认了"，是标题 `Verification-Grounded` 与末页 limitation 的
claim 层级错配。已在 `sections/04-conclusion.tex` 补三句：离散恒等式是
construction 而非几何发现；承载论文的测量是动作空间 0/10→20/20 与判据边界
及其代价；两者都不要求连续几何零过切。摘要与 cover letter 不动。

**交付**：新建 `docs/REVIEW-READINESS.md`（逐条裁决 + 6 处限定表 + 5 步证据链
答辩顺序 + R1/R2 风险 + 明确不做清单 + 收到意见后的自检顺序）；
`docs/DECISIONS.md` 加 D11。重编通过：21 页 / 236 词 / 20 篇 / 6 图 4 表 /
零 warning，禁用词干净。零实验、零数字改动、零后台服务。

**纪律**：不补真机、不扩工业件、不跑 B16 多次采样、不做参数化中间动作空间、
