
## 11:00 Genesis World + SolidCraft 可行性裁决（用户提问「训练有前途不」）

**裁决：不做训练线。** Genesis World 是机器人/具身 AI 多物理仿真（Rigid/FEM/MPM/Particle/uipc/SAP
+ Nyx 渲染 + Quadrants 编译器），SolidCraft 是参数化 CAD（SolidCore = SMLib 的 Rust port）。
两者都不含 CNC/刀具路径/材料去除/过切判据。关键论点：Genesis 状态里没有「去除体积 / 过切深度」，
强化学习没有可定义的 reward；SolidCraft 没有由刀具路径驱动的状态转移。与用户既定口径
「真实铣削没意义」「图表 6+4 已用满」冲突，故不新建实验线。

**落地（负结果程序 + 论文防守文字，不动任何实验数字）：**

  + `tests/test_physical_sim_feasibility.py`（6 tests）。六项必要能力作为接入契约，
  逐项证据来源标注 documentation / local_report；`--check` 锁死判定。
  结论：genesis_world 缺 6/6、solidcraft 缺 5/6、现有 dexel-OCL-CAMotics 全 supported。

  不抄搜索结果里指向错误 arXiv ID 的引用）。图表数量不变。
