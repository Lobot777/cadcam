# ADR-0001：以契约网关替代自由脚本执行

> 状态：已采纳（M1）｜日期：2026-11-04
> 影响范围：`src/cadcam/gateway/*`、`src/cadcam/adapters/model.py`

## 背景

让 LLM 操作 CAD 有两条路线：

**路线 A（自由脚本）**：给模型一个 `execute_code(script)` 工具，它自己写 FreeCAD Python。
CAD-Assistant（ICCV'25）等走这条路，优点是表达力无上限，缺点是——动作空间不可枚举，
因此不可静态校验、不可静态计费、不可静态回放。

**路线 B（封闭动作空间）**：把建模动作定义成有限个带契约的工具，模型只能组合调用。
表达力受限，但每个动作的参数、前置条件、后置条件、副作用都是已知的。

本文的核心论点之一（C1）是"能力类型化的工具契约能让计划期就被剪枝，而不是执行后才暴露错误"。
如果采用路线 A，这个论点无法成立——因为错误只能通过执行来发现。

## 决策

采用路线 B，并落实为四条具体约束。

### 1. 动作数是封闭的，且不含 `execute_code`

当前 9 个工具：`create_box` / `pocket` / `hole` / `inspect` / `faces` / `snapshot` / `rollback` / `snapshots` / `export_step`。

不提供 `execute_code` 的理由：一旦存在这个工具，模型可以绕过一切约束，
前面所有契约都退化成"建议"。调试用途的旁路放在测试脚本里，不进智能体的工具列表。

代价：M1 表达力只够做"块 + 矩形腔 + 圆柱孔"。圆角、阵列、自由曲面要等 M2 按同样方式增量添加。
这是刻意的——**先证明契约机制有效，再扩充动作集**。

### 2. 参数校验自己写，不引入 jsonschema

| 方案 | 优点 | 不采用的原因 |
|---|---|---|
| jsonschema 库 | 标准、省事 | 系统 Python 没有该包；且原生报错 `is not of type 'number'` 对 LLM 无信息量 |
| 手写校验（采纳） | 零依赖、报错可定制 | 需自己维护约 80 行 |

报错差异是决定性的：

```
jsonschema: "depth" is greater than the maximum of 39.5
本实现:     参数 depth = 42 超过上限 39.5
            hint: 允许范围 [0.05, 39.5]；本次可用切深由毛坯厚度 40 减保底余量 0.5 得出
```

后者能让模型一次改对，前者只能让它猜。

### 3. 交换格式统一为 STEP，状态标识用几何指纹

中间态一律存 STEP，不用 `FCStd`（含文档树，跨版本不稳）也不用 BREP（外部工具不可读）。

但**回滚正确性不能靠文件比对**：同一形状两次导出的 STEP 字节不同（头信息时间戳、拓扑编号重排）。
因此状态标识用 `state_hash` = 排序后的面签名（类型 + 面积 + 形心）+ 体积/面积/拓扑计数。

这直接回应了风险 R2（拓扑命名漂移）：**回滚后索引会变，指纹不会变**。
M2 的特征识别要以指纹为锚，而不是以面编号为锚。

### 4. 后置条件用体积守恒，而不是"没抛异常"

这是本 ADR 里最有论文价值的一条。

布尔运算的失败模式是"静默成功"：型腔打在已挖空的区域，`shape.cut()` 不报错，
返回的实体也合法，只是体积没变。只检查异常捕获不到这类错误。

因此每个切削动作声明理论切除体积，执行后校验实际切除量：

```
|实际切除 − 理论体积| / 理论体积 ≤ 2%
```

超出即判 `E_POSTCONDITION` 并自动回滚。误差方向还能用于诊断：

- 切除偏小 → 特征与已有材料重叠（错误信息给出重叠比例）
- 切除偏大 → 布尔异常或超出毛坯

实测：正常型腔偏差 0.00%，重复挖同一型腔被拦下（偏差 100%），孔打在空腔上被拦下。

## 后果

**收益**

- 错误在执行前/执行后两端被拦截，模型拿到的是结构化错误码 + 可执行建议；
- 失败动作自动回滚，会话不会进入脏状态（验收里 7 类错误全部 `状态未变=True`）；
- 每个动作都可静态描述，后续可做计划期校验（M4 的规划器直接吃 `inputSchema`）。

**代价与风险**

- 表达力受限，遇到底座上没有的几何要新增工具（预期 M2 增加约 6–8 个）；
- 2% 体积容差是经验值：粗加工分层切削、带拔模的腔可能超差，需要在 M3 用真实数据校准；
- 每动作一次子进程（约 0.25s），比进程内调用慢，但换来了崩溃隔离与状态可回滚。
