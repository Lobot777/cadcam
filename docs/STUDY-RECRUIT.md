## 1 招募话术

### 熟练组（发给车间 / 工艺 / 编程岗）

> 想请一位有 5 年以上数控编程或工艺编制经验的朋友帮个忙，做一个零件识图分类的小任务。
> 内容是看 186 张零件表面图，把每个面归到九个类别里（孔、型腔、凸台、台阶之类）。
> 分两次，第一次约 2 小时，中间有 20 分钟说明，隔几天后再来一次约 2 小时。
> 按小时给劳务费，**和答对多少完全无关**，判不出来可以直接点"判不了"。
> 不考能力、不排名、结果匿名，只用于一篇学术论文。
> 有一个条件：之前不能见过我们这批零件模型或标注资料，也不能和其他参加的人认识。

### 零基础组（发给非机械专业朋友）

> 想请你帮个忙做个识图实验，大概 4 小时，分两次。
> 看 186 张图，给每个高亮的面选一个类别，页面上有一张九类速查表可以照着看。
> **不需要任何机械背景**，事实上我们正是想找完全没学过的人；判不出来可以直接点"判不了"，
> 不算错。按小时给劳务费，和答对多少无关，随时可以退出。
> 唯一要求是日常用电脑没问题、能读完一页中文说明。

**不要说的话**：不要提"AI 标注""我们想知道机器标得对不对""这是要验证 xxx 的结论"。
说了会诱发迎合或对抗，污染作答。

## 4 主试指导语（两轮**逐字一致**，念出来）

> 这个任务是给零件上高亮的那个面选一个类别。页面上方有九类速查表，可以随时点开看。
> 每张图旁边列了这个面的面积、法向、位置、邻面，这些都是测出来的数，怎么用你自己决定。
> **判不出来就点"判不了"，这是合法答案，不算错、不扣分。**
> 选完可以顺手点一下"确定 / 拿不准 / 猜的"，这个也不影响结果。
> 请按从上到下的顺序做，不要跳，不要回头改。每做 70 题我会叫你休息 10 分钟。
> 中间有任何操作上的问题可以问我。

T0 与 T1 只差两处：T1 页面多一段判据提示；T1 开始前多一次培训（§4.2）。
**指导语本身一个字都不要改**，否则两轮不可比。

## 5 主试检查清单

### 每轮开始前

- [ ] 核对知情同意已签、编号 P_ 已分配、筛问卷已判组
- [ ] 用**普通窗口**打开页面（不要用无痕：进度靠 `localStorage` 保存，无痕关掉会丢）；
      受试者在页面右上填自己的编号（如 `P1`）。数据按「编号:轮次」分键存储，
      同一台电脑连续给多人使用无需清缓存，**换人只要改编号**
- [ ] 设备 / 浏览器 / 缩放 100% / 屏幕亮度与另一轮一致，记录在本子上
- [ ] 确认页面版本：`study/formal/annotate_T0.html`（裸标）或 `annotate_T1.html`（培训后），均 186 题
- [ ] **T0 轮不得**提供 `docs/STUDY-TRAINING.md` 或 `calibration.html`（含答案）
- [ ] 手机收走、无关网页关掉、屏幕主试可见
- [ ] 念指导语（逐字）；T1 轮把培训手册放在受试者手边
- [ ] 记录开始时间

### 过程中

- [ ] 每 70 题叫停休息 ≥10 分钟，记录休息次数与时长
- [ ] 不回答内容问题；把受试者的提问**原话记下来**（这本身是定性数据）
- [ ] 不提示、不纠正、不表露对错

### 收尾

- [ ] 点"导出 JSON"，确认条数 = **186**（以页面顶部 `0 / 186` 为准，缺多少记多少）
- [ ] 改名 `P1_T0.json` / `P1_T1.json`，存 `reports/annotation/study/responses/`
- [ ] 记录结束时间、总耗时、受试者主观感受一两句
- [ ] **不要把答案键或任何反馈给 T0 轮受试者**
