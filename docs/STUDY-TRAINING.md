## 第 1 页 · 九个类别

一个"面"是零件表面上的一整片连通区域。你的任务是判断**高亮的那一整片**属于哪一类，
不是判断整个零件是什么。

| 代号 | 中文 | 判定要点 |
|---|---|---|
| `stock` | 毛坯原始面 | 落在零件包围盒外表面上（x/y/z 某个极值面），没被加工过。水平顶底和四周侧壁都算 |
| `hole` | 孔 | 整圈圆柱壁（弧段占比≈1.00），或与之配套的孔底平面 |
| `pocket` | 型腔 | 材料被挖掉形成的腔：有底、被一圈立壁围合、底面 z 低于周围顶面 |
| `slot` | 槽 | 细长，两侧壁互相平行（法向相反），宽度明显小于长度 |
| `step` | 台阶 | 一级高度差的肩面，常与一段竖壁成对出现 |
| `boss` | 凸台 / 岛 / 销 | 凸出来的实体：整圈圆柱带顶盖，或四壁法向都朝外 |
| `fillet` | 圆角 | 两面的切向过渡，弧段占比≈0.25，自己不构成特征 |
| `chamfer` | 倒角 | 窄斜面，与邻面成固定角度（常见 45°）｜**本批不出现** |
| `freeform` | 自由曲面 | BSpline / Bezier，没有恒定半径｜**本批不出现** |

### 规则 0（最高优先级）　按特征归类，不按面型归类

类别说的是"这个面属于哪个**加工特征**"，面型（`Plane` / `Cylinder` / `BSplineSurface`）
只是 CAD 里的几何表示方式，**不是类别**。一个特征通常由好几个面组成——一个孔有圆柱壁 + 孔底，
一个凸台有顶面 + 四壁 + 肩面——**这些面全部归同一个类别**。

> **当"面型直觉"与"按特征归类"冲突时，一律以按特征归类为准。**
>
> **边界（真人实测后补）**：`stock` **不参与**按特征归类。它落在零件包围盒上、
> 不属于任何加工特征，即使紧挨着凸台、腔或台阶，也仍然判 `stock`。
> 首轮实测里培训后出现 61 处「原来判对、反而判错」，其中 P4 一人就有 10 处
> 是把 `stock` 误归进了邻面的特征——规则 0 被过度推广。别把这条规则用到毛坯面上。

本批 186 题的答案只落在 **7 个类别**：`stock / hole / pocket / slot / step / boss / fillet`。
`chamfer` 和 `freeform` 是通用九类体系里的成员，但这 10 个零件里**没有任何标注实例**，
选它们一定错（页面速查表已标注"本批 186 题不出现"）。

**最容易踩的一点**：本批有 6 个 `BSplineSurface` 面，是方→圆过渡的凸台侧壁，
真值**全部是 `boss`，不是 `freeform`**。原因是这批 STEP 用样条表示过渡曲面，
而标注体系里没有 freeform 实例（与 M2 的结论一致：BSpline 面在训练集里不存在，
按面型判必然误判）。见例 5。

## 第 1 页 · 三条判据

### 判据 ①　弧段占比：分开"圆角"和"整圈圆柱"

圆柱面页面上直接给了**弧段占比**，它等于：

```
弧段占比 = 面积 / (2π × 半径 R × 高度 h)
```

| 值 | 含义 |
|---|---|
| ≈ **0.25** | 只走了 ¼ 圈 → `fillet` 圆角（拐角过渡），不是孔也不是销 |
| ≈ **1.00** | 走满一圈 → 是真圆柱面，接着用判据 ② 分孔 / 销 / 腔壁 |
| 介于中间 | 结合邻面判断，拿不准点「判不了」 |

### 判据 ②　径向点积：直接读出凹 / 凸

圆柱面页面上还有一行**径向点积**，它是用 FreeCAD 在圆柱面参数中点取法向、
与该点的径向单位向量点乘得到的（题目包里已经量好，不需要你算）：

| 值 | 含义 |
|---|---|
| **+1.00** | 法向**背离**轴线 → 凸 → `boss`（销 / 圆柱凸台 / 岛外壁） |
| **−1.00** | 法向**朝**轴线 → 凹 → 孔壁、圆腔壁，或**圆角** |

这批零件 43 个圆柱面全部落在 ±1.00，没有中间值；`boss` 的 8 个面全 +1，
`hole` / `pocket` / `fillet` 的 35 个面全 −1。

> ⚠️ **凹不等于孔**：圆角也是 −1.00。所以 ① 和 ② 必须**联用**：
>
> | 弧段占比 | 径向点积 | 判成 |
> |---|---|---|
> | ≈0.25 | −1.00 | `fillet` 圆角 |
> | ≈1.00 | +1.00 | `boss` 销 / 圆柱凸台 |
> | ≈1.00 | −1.00 | `hole` 孔壁或 `pocket` 圆腔壁（再看有没有更低的底面） |
>
> 另外，**不要拿页面的「法向」和「形心」自己去点乘**：那个法向只是面上一点的
> 方向，题目包也没给圆柱轴心，自己算算不出 ±1。请直接读「径向点积」这一行。

### 判据 ③　平面：看邻面法向 + 邻面 z

| 现象 | 判成 |
|---|---|
| 四周立壁的**法向都朝外** | `boss` 凸台 |
| 四周立壁的**法向都朝内** | `pocket` 型腔 |
| 整段圆柱壁 + 更低处的水平底面 | `hole` 孔（底面也归 `hole`） |
| 水平面 z 夹在两个不同高度的顶面之间 | `step` 肩面 |
| 水平面落在包围盒极值上、周围没有立壁 | `stock` |

页面「邻面」一栏现在给出**每个邻面的法向与 z 范围**，
例如 `Plane 640 z42–52 n(0,-1,0)`。判凸台 / 型腔时看这一圈立壁的 `n(...)` 是都朝外还是都朝内；
找"有没有比当前面更低的底面"时看 `z`。两个量都是页面直接给的，不用猜。

判不准就点「判不了」——这是合法答案，不扣分，而且"判不了"率本身就是我们要统计的信息。

### 辅助：面积对账

面积都是实测值，加减能对上就说明拓扑关系判对了。例如一块水平面面积 1500 mm²，
若整块顶面是 80×80=6400，凸台占掉 70×70=4900，那么 6400−4900=1500，
这块面就是凸台周围的**台阶肩面**，不是腔底。

## 第 2 页 · 五个例题（数字已脱敏，不对应题库任何一题）

**例 1**　`Cylinder`，R=3，z 从 42 到 52（h=10），面积 47.1 mm²
→ 2πRh = 2π×3×10 = 188.5；47.1 / 188.5 = **0.25** → ¼ 圆弧 → **`fillet`**
（若误看成"Ø6 盲孔"就错了：¼ 段圆柱不可能是孔壁。）

**例 2**　`Cylinder`，R=5，h=6，面积 188.5 mm²
→ 188.5 / (2π×5×6) = **1.00** → 整圈圆柱。再看径向点积：**−1.00** + 更低的圆底面 → **`hole`**；
**+1.00** + 顶上小圆盖 → **`boss`**（销）。同样弧段占比 1.00，靠径向点积分开。

**例 3**　`Plane`（水平面），z=48，面积 1500 mm²；邻面里有一圈 70×4 的竖壁
→ 6400−4900=1500 对上了；邻面清单里能看到 `z48` 的肩面与 `z48–52` 的竖壁 → 70×70 凸台周围的**肩面** → **`step`**
（曾把这类面误判成"环形型腔"，检查四壁法向全朝外即可排除。）

**例 4**　`Plane`（水平面），z=44，面积 3618.9 mm²，四周被一圈立壁围住
→ 材料被挖掉、底面明显低于 z=48 的顶面 → **`pocket`**
（同一高度上还可能有别的水平面，**z 相同不代表类别相同**，要看它围合的是材料还是空腔。）

**例 5（两条规则打架时怎么办）**　`BSplineSurface`，面积约 400 mm²，z 从 44 到 50，
法向水平；邻面只有上下两块水平面（`n(0,0,1)`，分别在 z44 与 z50）
→ 按面型直觉该选 `freeform`，但**本批没有 freeform 实例**，且这块面连接的是同一个
凸起实体的上下两面 → 依**规则 0** 判 **`boss`**。
注意这 6 题的邻面里没有立壁，判据 ③ 的"四壁法向朝外"用不上；**规则 0 是唯一依据**。
拿不准就点「判不了」，但不要选 `freeform`。

## 第 2 页 · 七个最常见的错

1. 把 ¼ 圆弧圆角当成小盲孔 —— 先算弧段占比。
2. 把 Ø4 的整圆柱销当成 R2 圆角 —— 弧段占比 1.00，不是 0.25。
3. 把凸台四壁当成环形型腔 —— 看四壁法向朝外还是朝内。
4. 把孔底 / 腔底平面当成 `stock` —— 它在零件内部，不落在包围盒上。
5. 自己拿「法向」和形心硬算点积 —— 直接读页面给的「径向点积」即可，见 ⚠️。
6. 看到 `BSplineSurface` 就选 `freeform` —— 本批 6 个 BSpline 面真值全是 `boss`，
   见规则 0 与例 5；`freeform` / `chamfer` 在本批答案里根本不存在。
7. 把 `stock` 按邻面的特征归类 —— 规则 0 不适用于毛坯原始面，见规则 0 的「边界」。

**再者**：同一个特征的所有面归同一类；"判不了"永远比随机猜更有价值。

## 主试流程（20 分钟，逐项计时）

| 时间 | 做什么 |
|---|---|
| 0–3 min | 发手册，念一遍九个类别，强调"一个特征有好几个面，都归同一类" |
| 3–8 min | 先讲**规则 0**（按特征归类 + 本批只有 7 类 + BSpline 归 boss），再讲三条判据与 ①×② 组合表；带受试者把五个例题自己算一遍 |
| 8–10 min | 讲七个常见错与 ⚠️（凹不等于孔、别自己算点积、别选 freeform）；明确"判不了"合法、不计分 |
| 10–20 min | 打开 `calibration.html`，20 题当场点、当场看答案和解释；主试在场，只答操作问题 |

## 数据完整性（写进论文方法部分）

原先缺的两项已经补上，复现方式：

- **径向点积**：`scripts/annotate/polarity_worker.py` 在 FreeCAD 1.1.4 里对 10 个 STEP
  的 43 个圆柱面取参数中点 `normalAt`，与垂直于轴的径向单位向量点乘 →
  `reports/annotation/polarity.json`。全部为 ±1.00，无中间值，与既有标签零冲突。
  题目包里以 `face.radial_dot` 给出，页面显示为「径向点积」。
- **邻面 z**：`study_sample.py` 从 `geom/<part>.json` 的 `bbox` 取出每个邻面的
  z 范围与形心 z，写进 `samples.json` 的 `neighbors[].z_mm` / `centroid_z`，
  页面「邻面」一栏直接显示 `z42–52` 这样的范围。

**邻面法向**这一项比较特殊：数据一直在 `samples.json` 的 `neighbors[].normal` 里，
是页面渲染漏了没显示。现在 `build_card` 已把每个邻面的法向一起输出成 `n(0,-1,0)`，
并把显示上限从 6 个提到 8 个（13 题恰好有 8 个邻面，此前会被截掉两个），
判据 ③ 的"四壁朝外 / 朝内"才真正可用。
注意多数题只能看到**局部**一圈壁，法向给的是线索不是判决；判不准点「判不了」仍然合法。

仍剩一项限制：高亮面只靠红色区分，色觉障碍者需排除
（见 `docs/STUDY-RECRUIT.md`；后续可给高亮加描边）。

**两项补全合起来能解决多少**（对 206 面全量统计）：

| 弧段占比 / 径向点积 | 面数 | 结果 |
|---|---|---|
| 0.25 / −1.00 | 8 | 全部 `fillet`，两字段**唯一判定** |
| 1.00 或异常 / +1.00 | 8 | 全部 `boss`，**凸这一档 100% 可分** |
| 1.00 / −1.00 | 27 | 24 `hole` + 3 `pocket`，仍需邻面 z 找"更低的底"来分 |
| 平面（无极性） | 163 | 靠邻面法向 + 邻面 z |

也就是说：**极性彻底解决了"凸还是凹"，邻面 z 接手剩下的"孔还是腔"。**
两者是互补的，缺一个都会把人逼到「判不了」。

> 注意：这两项在 T0 与 T1 页面上**都会显示**（它们是可测量，不是答案），
> 但**只有 T1 的页首提示会教怎么读**。这个差别正是培训变量。
> "判不了"率实际能降多少，要等真人数据回来才能量化——这里是信息层面的上界。
