## 二、软件与环境（🔴 阻塞）

| 项 | 具体要求 | 验收方式 | 搞不定时的替代 |
|----|----------|----------|----------------|
| **FreeCAD** | 1.0.x 官方 Windows 安装包 | 命令行跑 `freecadcmd -c "print(1)"` 有输出 | 无（这是唯一必装项） |
| **FreeCAD 路径** | 告诉我 `freecadcmd.exe` 与 `FreeCADCmd` 的绝对路径 | 我写进配置 | — |
| **Python 宿主** | 3.12（或用 `uv` 管理） | `python --version` | 我可以用 uv 自建 |
| **pythonocc** | `conda install -c conda-forge pythonocc-core` | `import OCC` 成功 | 退化：只用 FreeCAD `Part.Shape`，精度略降 |
| **Siemens NX** | 🟡 2306 / 2406 / 2212 任一版本 | `NXBIN\run_journal.exe` 存在且可跑空脚本 | Mock 适配（基于 OCC 模拟 NX 行为） |
| **Qwen 通路** | 🔴 二选一：① DashScope API Key ② 本地 vLLM + 权重 | 一次 `chat.completions` 带 tool_calls 返回成功 | 无 |
| **Git** | 本地仓库即可（GitHub 连接器当前不可用） | `git init` | — |
| **CAMotics** | ⚪ G-code 仿真交叉验证 | 能加载 .nc 并渲染 | 自研 dexel 仿真（已有计划） |

> 提示：NX 与 FreeCAD 各自带独立 Python（NX 内置 3.8/3.10，FreeCAD 内置 3.11），**不能混用**，所以适配层做成独立进程 + RPC，这是设计前提，不是妥协。

## 四、数据与素材（🟡 最重要，也是论文的命门）

> 如果只能准备一件事，就准备这个：**零件 + 它的标准工艺答案**。代码和框架我能写，真值只有你能给。

### 4.1 零件（🔴 D3 就要）

- **5–10 个**，来自真实产品族优先：支架 / 法兰 / 端盖 / 腔体 / 连接块 / 板类
- 格式：`.step` 或 `.prt` / `.FCStd`（STEP 最通用，先给这个）
- 覆盖度：至少含 1 个"有型腔"、1 个"多孔系"、1 个"薄壁易变形"、1 个"深腔难加工"
- 命名：`P01_bracket_pocket.step`

### 4.2 每个零件的"标准答案"（🟡 W1）

最简单的方式：**你口述，我整理**。每题 3 分钟：

| 需要的信息 | 例子 |
|------------|------|
| 毛坯 | 100×80×30 铝块 |
| 材料 | Al6061 |
| 装夹方式 | 虎钳夹两侧，一次装夹 |
| 加工特征清单 | 1 个 60×40×12 型腔，4 个 M8 螺纹孔，2 个 Ø10 通孔 |
| 工序顺序 | 面铣 → 型腔粗 → 型腔精 → 钻孔 → 攻丝 |
| 刀具 | Ø12 平底立铣（粗）、Ø6 平底（精）、Ø8.5 钻、M8 丝锥 |
| 参考 G 代码（有就给） | 哪怕只是厂里在跑的 .nc 片段 |

### 4.3 数据授权（⚪ W4，但越早越好）

- 这些零件图纸是否涉及客户保密？
- 能否用于：① 本地实验 ② 论文插图 ③ 开源数据集
- 若涉密 → 走"全离线 + 脱敏 + 只发表合成族"路线，我会在计划里改数据章节

## 十、如果你只有 30 分钟

按这个顺序做三件事，其余都不急：

1. 装 FreeCAD 1.0，把安装路径发我
2. 开一个 DashScope / 阿里云百炼账号，把 Key 发我（或者告诉我显卡型号）
3. 找 3 个零件 STEP 放进 `data/inbox/`，每个零件用三句话告诉我"这活该怎么干"

有这三样，我第二天就能让你看到"输入一句话 → 自动建出型腔 → 导出 G-code → 仿真出图"的最小闭环。
